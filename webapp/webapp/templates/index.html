How do I… (common tasks)

Add zip codes for a new area

Edit config/regions.yaml. Add zips under an existing region or define a new one (e.g. South_Bay with Redondo/Torrance zips). Then use the Discovery card above with the region selected.

Check for duplicate drafts in Zoho before sending

Run python scripts/audit_drafts.py. Cross-references each draft against Leads + Already_Contacted + Archive. Flags real duplicates and legitimate follow-ups separately.

See which schools clicked the demo link

Run python scripts/show_clicks.py (add --since-days 7 for last week, --campaign followup to filter). Highlights "clicked but not replied" leads as second-follow-up candidates.

Mark a lead as do-not-contact

Quickest: in /review grid, click the DNC button on a row. For a specific school: /leads → search → click Edit ↑ → DNC button on the top card.

Find a specific school

Search bar on /leads does case-insensitive "contains" across name, website, and email. Click Edit ↑ on a row to open it in /review.

Re-run downstream after editing leads in Review

If you edited leads in Review (classified or filled in owner), they're ready_for_owner_lookup and need Phase 4 to run. Click Run downstream in the pipeline above. The banner at the top of this page appears when this is needed.

Age out stale leads + archive disqualified ones (weekly)

Run weekly, in this order:

  1. python scripts/run_close_stale.py --commit — marks sent-but-no-reply ≥ 7 days post-follow-up as closed_no_reply
  2. python scripts/run_cleanup.py --commit — moves disqualified statuses (online_system_exclude, closed_no_reply, bounced, do_not_contact) from Leads to Archive

Verify how many emails I've actually sent

Run python scripts/sent_email_count.py. Scans Zoho Sent folder, separates initial sends from follow-ups, lists any duplicate-send recipients.

What do the Review tabs mean?

  • Classify — needs_enrollment_system_classification: Phase 3 couldn't decide. Pick enrollment_method or DNC.
  • Owner review — needs_owner_review: Phase 4 couldn't find owner/email. Fill in what you can.
  • Pre-send polish — ready_to_send leads with blank owner_name. Add a name so the draft uses it instead of "Hi there".

A school's email is bouncing — what happens?

Phase 6 sync auto-detects mailer-daemon notifications and flips the lead to bounced with the SMTP error code in do_not_contact_reason. You get a 📭 alert email. Next cleanup run archives the row. No manual action needed.

I'm getting low replies — should I rework the pitch?

Not until ~80–100 sends with confirmed clean deliverability (mail-tester ≥ 9/10). Below that volume, 0 replies is noise, not signal. Check scripts/sent_email_count.py for your current send count.
