# Deprecated Zoho Setup

Pontora Outreach no longer uses Zoho Mail.

This file is intentionally kept only as a migration marker so older commits and
operator notes still have a stable reference path. Do not set up Zoho for new
outreach, and do not add Zoho credentials to GitHub Actions, Render, or `.env`.

Use `docs/setup_gmail.md` for the current Pontora Gmail workflow.
